## Hi, I'm Hoda

PhD student at [Linköping University](https://liu.se/en/employee/hodfa71) in the AI division (AIICS), working on LLM reasoning and alignment.

My research focuses on understanding how large language models think, from analyzing their internal geometry to improving how they learn through reinforcement learning.

### What I work on

- **LLM interpretability**: detecting reasoning failures from hidden-state geometry ([VANE](https://github.com/hodfa840/vane))
- **LLM safety**: type-aware unlearning of memorized secrets ([PSTU](https://github.com/hodfa840/pstu), under review)
- **RL for language models**: GRPO, PPO, and flow matching approaches to LLM fine-tuning
- **GPU systems**: benchmarking inference and fine-tuning across model families

### Selected work

| Project | What it does |
|---------|-------------|
| [VANE](https://github.com/hodfa840/vane) | Predicts LLM reasoning correctness from hidden-state trajectory geometry. No training required. |
| [PSTU](https://github.com/hodfa840/pstu) | Removes memorized secrets from LLMs via per-type saliency in weight space. Training-free, runs in seconds. |
| [llm-gpu-bench](https://github.com/hodfa840/llm-gpu-bench) | Benchmark suite for LLM inference speed, fine-tuning throughput, and VRAM usage across model families. |
| [GRPO-Math](https://github.com/hodfa840/GRPO-Math) | Fine-tuning LLMs with Group Relative Policy Optimization on math reasoning (GSM8K). |
